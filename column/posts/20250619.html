このコラムページは0から私の手で作成しているのですが、 久しぶりにコードを開くと、「あれ、どこをいじれはいいんだっけ？」とそれまでの内容を忘れてしまっていました。

なので今回はコラム投稿の方法を思い出せるようにまとめておきたいと思います。

新しい記事を作成する方法

まずはフォルダ構成のおさらいから。

column/

├─ column.html ← 一覧ページ

├─ posts/

│ ├─ 20250620.html ← 作る記事（例）

├─ /images/column/

│ ├─ 20250620-thumb.jpg ← 記事サムネイル画像

├─ /js/

│ ├─ column.js ← 一覧を自動生成するスクリプト

これらがコラム投稿時に使うファイルたちです。

それらを踏まえたうえで、説明を進めていきます。

1.記事ファイル(.html)を作成

column/post/フォルダ内に、日付を使ったファイル名で新しいHTMLファイルを作成する。
例：20250619.html

ファイルの中身はサンプルを参考にする。

20250610.htmlファイルがサンプルファイルなので、中身をコピペし、必要なところを書き換えて記事を書く。

2.サムネイル画像を用意する

/images/column/フォルダに、記事と同じ日付のファイル名でサムネイル画像を保存する。
例：20250619-thumb.jpg

画像例：

3.JavaScriptファイルに記事データを追加

/js/column.jsのposts配列に、以下のような情報を1行追加する： 


      {
        title: "記事タイトル",
        date: "2025-06-19",
        folder: "20250619",
        thumbnail: "../../images/column/20250619-thumb.jpg",
        description: "記事の概要や紹介文。"
      }

4.完了

このような操作で、自動的にコラム一覧に記事がカード表示されます。表示順もプルダウンから変更できます。
